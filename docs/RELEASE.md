## 上传前

1. 将当前目录作为仓库根目录，不上传父级开发目录或旧“小程序.zip”。
2. 运行 `npm test`，复查变更中没有个人 AppID、`project.private.config.json`、真实定位采样或额外素材。
3. 确认 Git 提交署名与邮箱；如需隐藏个人邮箱，使用你自己的 GitHub noreply 邮箱。不要编造身份。
4. 创建仓库后推送代码，确认 Actions 通过，再创建 `v0.1.0-beta.1` 标签，并标记为 prerelease。
5. 发布说明可采用下面的文字。不要把“准备完成”写成真机或素材许可已完成。
