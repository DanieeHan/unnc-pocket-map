# 底图导入

本仓库的 `miniprogram/assets/campus.png` 和 `campus.svg` 是原创网格占位图，用于运行和检查交互，不反映校园地形。学校衍生地图、官方 PDF、商业街原照片及带这些素材的旧截图均未打包。

## 使用自己的底图

1. 确认你有权使用和分发拟导入的图片；公开可访问的素材不自动意味着可重新分发。
2. 将 PNG 放入 `miniprogram/assets/campus.png`。逻辑画布固定为 **600×579**，可使用等比例高清图片；不要改变方向、裁切范围或长宽比而不调整点位。
3. 现有点位参考 2025-10-16 校方地图的图面位置。历史裁切信息见 `miniprogram/data/map-source.json`。如果使用不同绘制或裁切的地图，逐项调整 `places.js` 的 x/y 百分比及附属服务锚点，不能直接当成匹配。
4. 可编辑的源图可放在 `campus.svg`；小程序实际加载的是 PNG，修改 SVG 后需重新导出 PNG。
5. 校验地图边缘、中部、宿舍和主要教学楼锚点。真实定位还需独立的地理配准，见 `LOCATION.md`。
6. 确认完成后，把页面中的“示例底图 · 待导入”改成准确的素材来源/版本说明，并同步来源文档。不要在未经核对时标为官方或实测。

不建议把下载校方地图的自动脚本或学校原图当成仓库的默认依赖。现有源文件提供来源链接，开发者应自行决定并确认其使用范围。

## 重建占位图

```sh
npm run placeholder
```

生成脚本只接受不存在或与自身生成结果一致的文件。若已替换为其他地图，会拒绝覆盖；恢复占位图前请自行备份并移走该文件。
