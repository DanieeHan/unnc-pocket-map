# MapUNNC 演示与技术说明

更新：2026-10-04。地图用于查找校园地点与楼栋服务；真实定位尚未校准，步行路线未实现。

## 本地启动

在本项目根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8765/preview/`。运行期间不需要访问外部服务；如端口已占用，可改用 8766。浏览器预览共用页面逻辑与 WXML/WXSS，微信权限、分享与真机触摸仍需单独验收。

## 两分钟演示

1. 搜索 `TB`，说明支持中文、英文、简称和楼号；点结果观察居中。
2. 收藏杨福家楼，刷新后进入“我的收藏”，展示本机持久化。
3. 搜索 `麦当劳`，查看楼栋提示与入口确认说明。其标记表示 8 号楼导览分组，不代表店铺入口；复制的信息保留这一限制。
4. 回到地图，点带服务角标的楼栋，展开周边服务，选择其中一项。
5. 放大地图观察名称避让，拖动打断动画，点击空白关闭预览。
6. 点击定位按钮，说明真实定位待校准；结束于已经能稳定演示的搜索和收藏功能。

## 可解释的技术点

- 坐标：地点 x/y 为底图百分比。屏幕位置由底图尺寸、缩放和平移共同计算；图像、标记与定位圈使用同一相机状态。
- 标签：优先保留选中地点和重要楼栋，按屏幕包围盒避让；放大后优先在标记下方显示名称。隐藏的地点仍可以搜索。
- 动画：静态服务数量、排序和名称宽度只准备一次；动画只传递界面需要的标记字段。异步帧有失效标记，新的点击或拖动使旧动画失效，防止迟到的结果改变当前视角。
- 数据：66 条地点记录，收藏只存本机；校园图面来源日期为 2025-10-16，照片服务信息不代表当前营业状态。
- 定位：后续需采集分布在校园的真实参照点，拟合坐标变换，再用未参与拟合的点验收。合成数据测试只能验证数学与状态逻辑。
